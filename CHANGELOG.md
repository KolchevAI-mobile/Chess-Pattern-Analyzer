# Changelog

## [0.1.0] — 2026-11-14

Первый рабочий вертикальный срез: ник Lichess → разбор партий → диагноз.

### Добавлено

- **ML**: `analysis_version` и `engine_version` в ответе `POST /api/v1/analyze`;
  жёсткий потолок глубины `MAX_DEPTH=10`.
- **Backend**:
  - `POST /api/v1/import` — импорт партий Lichess по нику (`perfType=rapid|blitz`,
    `clocks=true`), с backoff на 429;
  - хранение партий, разборов и паттернов в PostgreSQL (Flyway `V1__init.sql`);
  - кэш разбора: повторный импорт тех же партий не запускает Stockfish;
  - `GET /api/v1/games`, `GET /api/v1/games/{id}` (ошибки постранично), `GET /api/v1/insights`.
- **Android**: экран ввода ника, импорт и разбор, карточка диагноза с паттернами,
  список партий; HTTP-таймаут 120 с.
- **Infra**: `infra/docker-compose.yml` с PostgreSQL 16 (healthcheck, том).
- **CI**: тесты ML, сборка backend, сборка APK.

### Известные ограничения

- Импорт синхронный, до 20 партий; очередь — M2.
- Авторизация — только ник и публичные партии; Lichess OAuth — M2.
- Кэш «всё или ничего»: при появлении новой партии выборка пересчитывается целиком
  (паттерны должны считаться по полному набору).
